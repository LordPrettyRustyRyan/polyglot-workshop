## Features:

* Interactive command-line interface with custom command parsing and ASCII art.
* Built-in commands tailored for personal portfolio, history, and utilities.
* Fully typed codebase for robust state and command handling.

## How To Run

```bash
git clone https://github.com/LordPrettyRustyRyan/terminal.git
cd web-terminal
npm install
npm run dev
```
