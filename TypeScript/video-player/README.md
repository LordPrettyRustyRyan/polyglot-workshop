## Features:

* Custom web-based video player interface.
* Responsive video playback layout.
* Custom playback controls and UI.

## How To Run

```bash
git clone https://github.com/LordPrettyRustyRyan/video-player.git
cd polyglot-workshop/TypeScript/video-player
npm install
npm run dev
```
